# Apple 참조와 Windows 대체

참조는 macOS Finder와 Photos의 정보 밀도, 사이드바, 통합 도구막대, 콘텐츠 우선 그리드, 짧은 이동이다. Apple의 상표, SF Pro, SF Symbols, 트래픽 라이트 버튼, 메뉴 막대는 가져오지 않았다.

비교 대상은 이 저장소의 `docs/design/window-prototype.html`과 Apple HIG의 공개 문서다. 실제 macOS 화면과 나란히 캡처하지 못했으므로 픽셀 일치를 주장하지 않는다.

| 구역 | Finder / Photos에서 가져올 성질 | 이 셸의 구현 | 차이 |
|---|---|---|---|
| 창 | 하나의 창, 두꺼운 안쪽 카드 없음 | 네이티브 프레임 안의 단일 컬럼 | OS 제목 표시줄이 시안보다 위에 하나 더 있다 |
| 사이드바 | 풀높이, 약한 선택, 그룹 헤더 | 236px, 1100px 미만에서 196px, 그룹 둘 | 블러 재질 없음. 불투명 배경 |
| 도구막대 | 뒤로, 제목, 검색, 보기 | 60px. 브랜드, 탐색, 제목, URL, 정보 | 캡션 버튼은 이 줄에 없다 |
| 검색 필드 | 낮은 채움, 포커스 링 | 32px, 포커스 테두리 | 분석 엔진 없음 |
| 그리드 | 여백이 작고 선택만 강조 | 4열, 1100px 미만 3열, 둥근 12px | 샘플 그라데이션. 사진 파일 아님 |
| 정보 패널 | 오른쪽, 폭이 부드럽게 변함 | 298px / 265px, 스프링 또는 즉시 | 메타데이터는 예시 문구 |
| 상태 | 얇은 하단 | 60px. 선택 수, 모션, 테마, 다운로드 | 전송 진행 없음 |
| 글자 | 시스템 산세리프, 12–13px, 제목 큼 | Segoe UI Variable Text. 없으면 Segoe UI | SF Pro 미포함 |
| 아이콘 | 한 세트, 같은 획 | 16px 기하 아이콘. Segoe MDL2나 SF Symbols 아님 | 프로토타입 SVG와 경로가 같지 않음 |
| 색 | 중성 배경, 포인트 색은 선택과 주행동 | 라이트/다크 토큰. 액센트 `#007AFF` / `#0A84FF` | Windows 액센트 색은 아직 읽지 않음 |
| 모션 | 짧고, 줄일 수 있음 | `docs/design/MOTION_TOKENS.md` | 프레임 시간 미측정 |

프로토타입 CSS의 창 배경은 `#FFFFFF`, 사이드바는 `rgba(244,245,248,.81)`, 도구막대는 반투명이다. 구현 토큰은 불투명 값으로 바꿨다. Win11 Mica는 원격 데스크톱과 고대비에서 깨지기 쉬워 WO-UI-00에서는 넣지 않았다.
