# UI 검토

검토일: 2026-11-01. 자동 검사 결과는 테스트를 실행한 뒤 이 파일의 결과 절을 갱신한다. 갱신 전에는 그 절을 통과로 읽지 않는다.

## 구현

- PySide6 Qt Quick. HTML 프로토타입은 `docs/design/window-prototype.html`에만 있고 앱이 그것을 띄우지 않는다.
- 창은 `native-frame`. 캡션 버튼은 Windows 기본이다.
- 화면은 도구막대, 사이드바, 샘플 그리드, 정보 패널, 상태 줄이다.
- 샘플 12개는 네트워크를 쓰지 않는다. 다운로드 버튼은 저장하지 않고 안내만 보여 준다.
- 글꼴은 Segoe UI Variable Text다. Apple 글꼴과 기호 폰트는 포함하지 않았다.
- 아이콘은 앱이 그리는 16px 기하 도형이다.

## 시안과의 차이

시안은 60px 도구막대 안에 창 버튼을 그렸다. 그 버튼은 브라우저에서 동작하지 않는다고 시안이 스스로 적는다. 이 셸은 그 버튼을 생략하고 OS 제목 표시줄을 남긴다. 그래서 픽셀이 같지 않다. 블러와 Mica도 없다.

환경: Windows, Python 3.12 venv, PySide6. 플랫폼은 테스트에서 `offscreen`, 스타일은 Basic.

## 아직 하지 않은 검증

- 실제 macOS Finder, Photos와의 나란히 비교
- Win+Z, Snap, Alt+Space, Alt+F4, 제목 더블 클릭, 모서리 드래그
- 모니터를 넘는 DPI 전환, 고대비 테마
- 스프링이 300ms에 안착하는지에 대한 프레임 측정
- 화면 읽기 프로그램으로 순서 읽기

이 항목이 끝나기 전에는 고충실도 재현 완료라고 하지 않는다.
