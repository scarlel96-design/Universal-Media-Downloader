# 성능 기준선

판정: **NOT RUN**.

같은 조건의 허가된 테스트 자료로 4K Video Downloader+와 우리 앱을 비교하지 않았다. 경쟁 제품을 실행하지 않았다. 실행하면 업데이트 확인, 계정 화면, 네트워크 접속이 생길 수 있고, 그 관찰은 사용자 승인 없이 하지 않기로 했다. 우리 다운로드 엔진도 아직 없다.

| 측정 | 결과 | 이유 |
|---|---|---|
| 단일 영상 메타데이터 시간 | NOT RUN | 앱 미실행, 샘플 URL 미지정 |
| 재생목록 처리량 | NOT RUN | 동일 |
| 동시 전송 수와 속도 | NOT RUN | 동일 |
| 재개 후 무결성 | NOT RUN | 동일 |
| CPU, 메모리, 1,000건 목록 | NOT RUN | 동일 |
| 시작 시간 | NOT RUN | 동일 |

설계서의 동시성 기본값(이미지 12, 호스트 3, 영상 2)과 5,000건 55 FPS는 목표가 아니라 아직 재지 않은 제안이다. 실측 전에는 측정값으로 적지 않는다.

나중에 재려면 사용자가 권리를 가진 로컬 파일이나 공개 테스트 픽스처만 쓰고, 경쟁 제품 실행과 네트워크 캡처를 먼저 승인해야 한다. 라이선스 키와 쿠키는 로그에 남기지 않는다.
